# Hub PC Monitor v0.5.4

Windows x64 · 2026-10-27 · 性能主题更新版

这是带屏幕 Hub 的独立 USB 上位机，无需让佳点控制工具一直运行。当前已实测 V1PRO / V1P（320×170）；V2（320×240）已预留布局和协议支持，尚未完成实机验证。

## 安装与使用

1. 解压整个压缩包，运行 `HubPcMonitor-v0.5.4-Setup.exe`。
2. 安装界面可选择登录 Windows 后自动启动、安装后启动。CPU 温度组件需要管理员确认，会安装 PawnIO 和后台传感器服务；不需要温度可取消该项。
3. 完全退出佳点控制工具和其他占用此 Hub 的程序，包括托盘图标。插好 Hub。
4. 双击系统托盘里的 Hub PC Monitor 图标打开主界面。通常会自动连接。
5. 若旧固件不能报告型号，首次连接会要求选择实际型号：V1PRO/V1P 为 320×170，V2 为 320×240。请按购买型号选择，记录仅保存在这台电脑。
6. 选择主题。关闭窗口或最小化会继续在托盘运行；右键托盘图标，选择 `Exit` 才会完全退出并释放 USB。

需要 Windows 10/11 x64、系统自带 Windows PowerShell 5.1 和 .NET Framework 4.8。USB 控制接口必须已安装兼容驱动；如无法枚举或访问被拒绝，先退出厂商上位机并检查设备管理器中的设备驱动。不要替换普通 Hub/键盘/鼠标接口的驱动。

## 六个主题

- **性能监控**：CPU 使用率和温度、RAM 使用率/容量、CPU 频率区间百分比（当前 GHz）、GPU 占用率（GPU 温度）、电脑配置、USB 输入电压。
- **默认时钟**：本地时间与平滑秒进度条。
- **DeepSeek 时钟**：插画气泡时钟。
- **ChatGPT 时钟＋余额**：余额查询默认关闭，仅在该主题出现查询勾选项。启用后读取本机 Codex 登录状态查询额度；未登录或查询失败时隐藏余额，继续显示时钟。换电脑不会携带原电脑账号。
- **bongocat**：需用户另外安装 vladelaina/BongoCat（本项目验证版本 v1.14.0），不包含 BongoCat 软件或模型。选择本机的 BongoCat.exe 后映射角色画面；不能将模型窗口最小化或用 BongoCat 自身功能关闭显示。Hub 优先模式可隐藏桌面角色并继续采集，正常停止/退出时恢复。
- **音乐律动**：读取 Windows 默认播放设备的声音，24 段黑黄频谱与时钟。无需麦克风；系统静音、音量为零或音乐输出到另一设备时，可能看不到律动。

屏幕支持左转 90°、右转 90°和上下翻转 180°；电脑预览保持正常方向。实际 FPS 受 USB、固件和画面变化量限制，调度上限不等于实屏刷新率。

## 常见问题

- **CPU 温度为 `--`**：确认已安装可选温度组件，允许了管理员提示，且硬件受支持。服务名为 `HubPcMonitorSensors`。
- **GPU 占用或主频为 `--`**：系统性能计数器未就绪、驱动不支持或读取失败；软件不会用固定值冒充。
- **退出后桌面 BongoCat 没恢复**：如果曾强制结束上位机，请从 BongoCat 托盘退出并重新打开 BongoCat。
- **电脑休眠或退出程序**：实时画面停止更新；设备固件不会独立采集电脑信息。
- **卸载**：Windows“已安装的应用/应用和功能”中卸载 Hub PC Monitor。可选择移除温度服务；共享的 PawnIO 驱动不会被自动删除。
