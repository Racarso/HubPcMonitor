- 预设 8 个经官方资料核实的 Intel/AMD 型号，严格匹配型号后缀；未知型号不猜测百分比。

# v0.5.0 · 2026-10-26

首个分享发布版本，整合此前 0.4.36 的功能：

- 独立 USB 显示、断线自动重连、安装与卸载、可选登录自启、托盘退出。
- 六种主题，支持设备旋转且预览不旋转。
- 性能主题显示 CPU 使用率及温度、内存、CPU GHz、GPU 占用率、配置和输入电压；字体按像素网格绘制。
- 可选 CPU/GPU 温度后台组件。
- BongoCat 后台捕获、最新帧缓存、变化区域传输、可选降色/细微变化过滤、分批校正和分区精度。
- 战术频谱的系统播放回环采集、24 段频谱和平滑柱形。
- ChatGPT 额度查询默认关闭，不分发账号配置。

本次发布整理：

- 统一安装包、程序文件属性和卸载信息版本号为 0.5.0。
- 去掉开发机序列号记录；首次连接旧固件时允许用户确认实际型号。
- 发布目录只包含安装程序、说明、校验值和第三方许可。

已知限制：V2 尚未实测；设备 USB 吞吐限制仍在；CPU 频率/GPU 统计与任务管理器可能存在采样差异；受保护音频不保证能采集。
